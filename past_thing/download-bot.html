📋 설치 방법 (5분)

  1. 위 버튼으로 압축 파일 다운로드
  2. 압축 해제: tar -xzf upbit-smart-bot-v2.1-safe.tar.gz
  3. 폴더 이동: cd upbit-smart-bot-v2.1-safe/
  4. 패키지 설치: pip install pyupbit pandas numpy
  5. API 키 설정: cp api_keys.json.example api_keys.json
  6. api_keys.json 파일을 열어서 실제 API 키 입력
  7. 실행: ./start-smart-bot.sh 또는 python3 upbit-smart-bot.py

⚠️ 주의사항

  • 시뮬레이션 모드가 기본입니다 (실제 거래 안 됨)
  • 실전 모드는 코드에서 주석 해제 후 사용
  • 소액(10-50만원)으로 먼저 테스트하세요
  • API 키에 출금 권한은 절대 부여 금지
  • api_keys.json 파일은 Git에 올리지 마세요
