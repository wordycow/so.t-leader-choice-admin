so.t – 빗썸코인 (단타 NOW)

데이터 로딩중…
• NOW=지금 진입 후보 / 대기=WAIT / 진입금지=OUT(손절 터치)
• 기준가(시트)=픽 생성 시점 값(갱신 때만 바뀜) / 현재가(실시간)=15초 갱신(서버 live → 실패시 빗썸 API 폴백)
• 중요: “코인 교체/새 코인 등장”은 refreshAll이 새로 돌 때만 바뀜. 트리거가 멈추면 픽은 고정됨.
오늘의 픽을 가져오는 중…
지금 진입 후보(NOW)
-
주의: 이 페이지는 정보 제공/학습용. 수익 보장 없음. 단타/잡코인은 손실 위험이 큼. 본인 책임.
진입금지(OUT)이면 “그 코인은 오늘 진입 금지”로 보고 다음 NOW 후보로 넘어가.
• 펌프(pump) = 과거 특정 기준(+수익률 & 거래대금 급증)을 만족한 “급등일”
• “펌프:7d” = 7일 전쯤 급등일이 있었다(너무 최근 펌프는 위험이라 단타에서 제외되기도 함)
