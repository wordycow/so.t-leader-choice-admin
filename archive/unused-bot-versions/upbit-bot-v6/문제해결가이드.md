## 연결 오류 (ERR_CONNECTION_REFUSED)

### 증상
- 브라우저에서 `http://localhost:5000`에 접속 시 "연결할 수 없음" 오류
- "ERR_CONNECTION_REFUSED" 메시지 표시

### 원인
1. Python이 설치되지 않음
2. 필수 라이브러리가 설치되지 않음
3. 봇이 실행되지 않음
4. 포트 5000이 차단됨

### 해결 방법

#### Step 1: Python 설치 확인
```cmd
python --version
```

**결과:**
- ✅ `Python 3.x.x` 표시 → 다음 단계로
- ❌ `'python'은(는) 내부 또는 외부 명령...` → Python 설치 필요

**Python 설치:**
1. https://www.python.org/downloads/ 접속
2. "Download Python" 버튼 클릭
3. 설치 파일 실행
4. **⚠️ 중요:** "Add Python to PATH" 체크박스 반드시 체크!
5. "Install Now" 클릭
6. 설치 완료 후 **컴퓨터 재시작**

#### Step 2: 라이브러리 설치
```cmd
설치시작.cmd (더블클릭)
```
또는 수동 설치:
```cmd
pip install Flask flask-cors pyupbit pandas numpy requests
```

#### Step 3: 봇 실행
```cmd
START.cmd (더블클릭)
```

#### Step 4: 콘솔 창 확인
봇이 정상 실행되면 다음과 같이 표시됩니다:
```
 * Running on http://0.0.0.0:5000
Press CTRL+C to quit
```

## Python 설치 문제

### 문제 1: "Add Python to PATH" 를 체크 안 함

**증상:**
```cmd
python --version
'python'은(는) 내부 또는 외부 명령...
```

**해결 방법:**

**옵션 A: Python 재설치 (권장)**
1. Python 완전히 제거 (제어판 → 프로그램 제거)
2. https://www.python.org/downloads/ 에서 다시 다운로드
3. **"Add Python to PATH" 체크!**
4. 설치 후 컴퓨터 재시작

**옵션 B: 수동으로 PATH 추가**
1. "내 PC" 우클릭 → 속성
2. "고급 시스템 설정"
3. "환경 변수"
4. "시스템 변수"에서 "Path" 선택 → "편집"
5. "새로 만들기" 클릭
6. Python 설치 경로 추가:
   - `C:\Users\사용자명\AppData\Local\Programs\Python\Python311`
   - `C:\Users\사용자명\AppData\Local\Programs\Python\Python311\Scripts`
7. 확인 → 컴퓨터 재시작

### 문제 2: Python 버전이 너무 낮음

**최소 요구 사항:** Python 3.8 이상

**확인:**
```cmd
python --version
```

**해결:**
- Python 3.8 미만이면 최신 버전으로 업그레이드

## 라이브러리 설치 오류

### 문제 1: pip 명령어를 찾을 수 없음

**증상:**
```cmd
pip install Flask
'pip'은(는) 내부 또는 외부 명령...
```

**해결:**
```cmd
python -m pip install Flask
```

### 문제 2: 설치 중 권한 오류

**증상:**
```
ERROR: Could not install packages due to an OSError: [WinError 5] 액세스가 거부되었습니다
```

**해결:**
1. `설치시작.cmd` 에 우클릭
2. **"관리자 권한으로 실행"** 선택

### 문제 3: 인터넷 연결 오류

**증상:**
```
Could not fetch URL https://pypi.org/...
```

**해결:**
1. 인터넷 연결 확인
2. 방화벽/백신 프로그램 일시 비활성화
3. 다시 시도:
```cmd
pip install Flask flask-cors pyupbit pandas numpy requests
```

### 문제 4: 특정 라이브러리 설치 실패

**해결:**
하나씩 설치:
```cmd
pip install Flask
pip install flask-cors
pip install pyupbit
pip install pandas
pip install numpy
pip install requests
```

## 포트 충돌 문제

### 증상
```
OSError: [WinError 10048] 각 소켓 주소(프로토콜/네트워크 주소/포트)는 하나만 사용할 수 있습니다
```

### 원인
- 포트 5000을 다른 프로그램이 사용 중

### 해결 방법

#### 옵션 A: 다른 프로그램 종료
```cmd
netstat -ano | findstr :5000
```
→ 마지막 숫자(PID) 확인

작업 관리자 → "세부 정보" 탭 → 해당 PID 프로세스 종료

#### 옵션 B: 다른 포트 사용
`upbit-smart-bot-v6.py` 마지막 부분 수정:
```python
# 변경 전
app.run(host='0.0.0.0', port=5000, debug=False)

# 변경 후 (예: 5001 사용)
app.run(host='0.0.0.0', port=5001, debug=False)
```

그리고 브라우저에서 `http://localhost:5001` 접속

## 봇이 시작되지 않음

### 문제 1: START.cmd 실행 시 바로 종료됨

**해결:**
1. START.cmd 우클릭 → "편집"
2. 마지막 줄 확인:
```cmd
pause
```
- 있으면 OK → 오류 메시지 확인
- 없으면 추가

### 문제 2: Python 스크립트 오류

**증상:**
```python
ModuleNotFoundError: No module named 'flask'
```

**해결:**
```cmd
pip install flask
```

### 문제 3: 설정 파일 오류

**증상:**
```python
FileNotFoundError: [Errno 2] No such file or directory: 'config.json'
```

**해결:**
- 정상 동작 (파일이 자동 생성됨)
- 브라우저에서 API 키 입력하면 생성됨

### 문제 4: API 키 오류

**증상:**
```python
{'error': {'message': 'Invalid API Key', 'name': 'invalid_access_key'}}
```

**해결:**
1. 업비트 웹사이트 로그인
2. 고객센터 → Open API 관리
3. API 키 확인/재발급
4. 봇 대시보드에서 API 키 다시 입력

## 자주 묻는 질문 (FAQ)

### Q1. 실행 후 "localhost 페이지를 열 수 없음" 이라고 나와요

**A:** 
1. START.cmd 창이 여전히 열려 있는지 확인
2. 콘솔에 "Running on http://0.0.0.0:5000" 이 표시되는지 확인
3. 표시되지 않으면 위의 오류 메시지 확인

### Q2. 설치는 됐는데 봇이 자꾸 꺼져요

**A:**
1. START.cmd 창을 **절대 닫지 마세요**
2. 봇을 종료하려면:
   - 브라우저에서 "⏸ Bot Stop" 클릭
   - 또는 콘솔 창에서 `Ctrl+C`

### Q3. "연습 모드"와 "실전 모드"의 차이는?

**A:**
- **연습 모드:** 실제 거래 없음, 가상으로 시뮬레이션, 무료
- **실전 모드:** 실제 거래, 실제 수익/손실, 라이선스 필요 (10 USDT ~ 10일)

### Q4. 라이선스는 어떻게 구매하나요?

**A:**
1. 대시보드에서 "💎 라이선스 활성화" 클릭
2. 표시된 USDT 주소로 송금 (TRC-20 네트워크)
3. 거래 완료 후 TXID 복사
4. TXID 입력란에 붙여넣기 → "확인 및 활성화" 클릭
5. 자동으로 라이선스 활성화됨

### Q5. 컴퓨터를 끄면 봇도 멈추나요?

**A:**
- 네, 현재 버전은 로컬에서만 실행됩니다
- 24시간 운영하려면:
  - 컴퓨터를 계속 켜두거나
  - VPS (가상 서버)를 사용하세요

### Q6. 여러 개의 계정으로 동시에 운영 가능한가요?

**A:**
- 불가능 (현재 한 번에 하나의 계정만)
- 여러 계정을 운영하려면:
  - 폴더를 복사해서 각각 실행
  - 포트 번호를 다르게 설정 (5000, 5001, 5002...)

### Q7. 봇이 수익을 보장하나요?

**A:**
- **아니요!** 암호화폐 거래는 손실 위험이 있습니다
- 봇은 전략을 자동으로 실행할 뿐, 수익을 보장하지 않습니다
- **반드시 연습 모드로 충분히 테스트 후 소액으로 시작하세요**
