## 🛡️ **Level 1: 기본 보호** (5분)

### **1. 라이선스 주소를 내 것으로 고정**

**현재 문제:**
```python
LICENSE_CONFIG = {
    'usdt_address': 'TLb5D3uDQjPQt6CzATM21t21etxGsSvtbt',  # 누구나 볼 수 있음
}
```
→ 친구가 이 주소를 자기 주소로 바꾸면 끝

**해결책:**
```python
# 코드 내부에 주소를 숨기기 (난독화)
_addr = lambda: ''.join([chr(x) for x in [84,76,98,53,68,51,117,68,81,106,80,81,116,54,67,122,65,84,77,50,49,116,50,49,101,116,120,71,115,83,118,116,98,116]])
LICENSE_CONFIG = {
    'usdt_address': _addr(),
}
```

**효과:**
- ✅ 일반 사용자는 주소를 찾기 어려움
- ❌ AI나 개발자는 쉽게 찾을 수 있음

## 🔐 **Level 2: 중급 보호** (30분)

### **방법 A: PyInstaller - 실행 파일화**

#### **설치:**
```cmd
pip install pyinstaller
```

#### **빌드:**
```cmd
pyinstaller --onefile --noconsole --name="UpbitBot" upbit-smart-bot-v6.py
```

#### **옵션 설명:**
- `--onefile`: 단일 `.exe` 파일 생성
- `--noconsole`: 콘솔 창 숨기기
- `--name`: 실행 파일 이름
- `--icon=bot.ico`: 아이콘 설정 (선택)

#### **결과:**
```
dist/
└── UpbitBot.exe  (약 30MB)
```

#### **장점:**
- ✅ `.py` 파일 없이 `.exe`만 배포
- ✅ 일반인은 코드 확인 불가
- ✅ 디컴파일 어려움

#### **단점:**
- ❌ 파일 크기 큼 (30MB+)
- ❌ 백신이 오진 가능
- ❌ 전문가는 디컴파일 가능

from license_protection import LicenseValidator

# 글로벌 변수
license_validator = LicenseValidator()

def check_license():
    """라이선스 검증 (30분마다 자동 호출)"""
    txid = bot_state.get('license', {}).get('txid')
    if not txid:
        return False
    
    is_valid = license_validator.validate(txid)
    
    if not is_valid:
        # 라이선스 무효! 봇 즉시 중지
        status = license_validator.get_status()
        log("LICENSE", f"❌ 라이선스 검증 실패: {status['error']}")
        bot_state['running'] = False
        return False
    
    return True

# 봇 메인 루프에 추가
def bot_main_loop():
    while bot_state['running']:
        # 30분마다 라이선스 확인
        if not check_license():
            log("LICENSE", "⚠️ 라이선스 무효로 봇 중지")
            break

## 💰 **추가 보호: 머신 ID 바인딩**

### **개념:**
**"하나의 라이선스는 하나의 컴퓨터에서만 실행"**

### **구현:**
이미 `license_protection.py`에 구현되어 있습니다!

```python
def get_machine_id():
    """MAC 주소 기반 고유 ID"""
    mac = uuid.getnode()
    system_info = f"{platform.system()}:{platform.node()}:{mac}"
    return hashlib.sha256(system_info.encode()).hexdigest()[:16]
```

### **효과:**
```
친구 A: TXID로 라이선스 구매 → 컴퓨터 A에서 실행 ✅
친구 B: 같은 TXID로 실행 시도 → 컴퓨터 B에서 실행 ❌

오류: "License is bound to another machine"
```
