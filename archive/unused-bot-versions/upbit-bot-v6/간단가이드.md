# 🚀 업비트 스마트 봇 v6.0 - 간단 가이드

## 💰 **가격 정책**

```
1 USDT = 1일 (비례 계산, 소수점 버림)
최소 금액: 10 USDT

예시:
• 10 USDT → 10일
• 12.4 USDT → 12일 (0.4는 버림)
• 15 USDT → 15일
• 20 USDT → 20일
• 30 USDT → 30일
```

---

## 🎯 **사용 방법**

### **1단계: 설치**
```
설치시작.cmd 더블클릭
```

### **2단계: 연습 모드 테스트**
```
START.cmd 더블클릭
→ 🟢 연습 모드로 24시간 이상 테스트
→ 수익 확인
```

### **3단계: 라이선스 구매**
```
1. "라이선스 활성화" 버튼 클릭
2. 원하는 금액의 USDT 전송 (최소 10 USDT)
   → TLb5D3uDQjPQt6CzATM21t21etxGsSvtbt (TRC-20)
3. TXID 입력
4. 자동 검증
5. 전송한 금액만큼 일수 활성화!
```

### **4단계: 실전 전환**
```
1. 🔴 실전 모드 버튼 클릭
2. 경고 확인
3. Bot Start!
```
