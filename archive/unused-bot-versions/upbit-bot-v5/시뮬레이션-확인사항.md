# 🔍 시뮬레이션 모드에서 확인할 수 있는 것들

## 📊 **시뮬레이션 모드란?**

**실제 주문은 실행되지 않지만**, 봇이 **어떤 판단**을 하고 **언제 매수/매도**할지를 **미리 볼 수 있는 모드**입니다!

---

## ✅ **1. 웹 대시보드에서 확인 가능한 것들**

### **🌐 http://localhost:5000 접속 시:**

#### **📊 상단 상태 바**
```
🟢 실행 중 (Running)  또는  ⚪ 정지 (Stopped)
마지막 업데이트 시간
```

#### **💰 현재 잔고 정보**
```
┌─────────────────────────────────┐
│ 💵 현재 KRW 잔고                │
│    2,345,678 원                 │
│                                 │
│ 🌱 초기 시드                    │
│    2,000,000 원                 │
│                                 │
│ 💎 총 수익                      │
│    +345,678 원 (+17.3%)         │
└─────────────────────────────────┘
```
- **현재 KRW 잔고**: 지금 내가 가진 원화
- **초기 시드**: 봇 시작할 때의 원화 (절대 안 건드림)
- **총 수익**: 초기 대비 얼마나 벌었는지

#### **🪙 보유 코인 목록**
```
┌──────────────────────────────────────────┐
│ 코인       보유량      평가액     수익률 │
├──────────────────────────────────────────┤
│ DOGE    1234.56    45,678원   +3.5% 🟢 │
│ XRP       10.00     8,900원   -2.1% 🔴 │
│ BTC        0.001   89,000원   +8.9% 🟢 │
│ SOL        0.25    35,000원   +12.3% 🟢│
└──────────────────────────────────────────┘
```
- 각 코인별 **보유 수량**
- **현재 평가액** (지금 팔면 얼마나 받을지)
- **수익률** (평균 매수가 대비)
- 🟢 플러스 / 🔴 마이너스 표시

#### **💎 수익 재투자 내역**
```
┌─────────────────────────────────────┐
│ 수익으로 자동 투자된 코인들:       │
├─────────────────────────────────────┤
│ 2024-02-15 18:30  SOL   10,000원  │
│ 2024-02-15 19:45  XRP   10,000원  │
│ 2024-02-15 21:20  BTC   10,000원  │
└─────────────────────────────────────┘
```
- 매도해서 **수익이 났을 때**
- 자동으로 **SOL → XRP → BTC → HBAR** 순서로
- **1만원씩** 투자한 내역

#### **📜 최근 거래 내역**
```
┌────────────────────────────────────────────┐
│ 시간          타입    코인     금액/수익  │
├────────────────────────────────────────────┤
│ 18:30:25  [시뮬] 매수  DOGE   6,000원   │
│ 18:45:10  [시뮬] 매수  XRP   10,000원   │
│ 19:20:33  [시뮬] 매도  DOGE  1차 익절   │
│ 19:20:35  [수익투자]   SOL   10,000원   │
└────────────────────────────────────────────┘
```
- **[시뮬]** 표시로 시뮬레이션임을 확인
- 언제 어떤 코인을 얼마에 샀는지
- 언제 팔았는지
- 수익 재투자는 언제 했는지

## ✅ **4. 시뮬레이션으로 확인해야 할 핵심 사항들**

### **🎯 매수 로직 확인:**

#### **✓ 1단계 매수 (테스트)**
```
조건: RSI 28~30
금액: 6,000원
목적: 코인이 관심 대상인지 확인
```
- 로그에서 **"1단계 매수"** 찾기
- RSI 값이 28~30 범위인지 확인

#### **✓ 2~4단계 매수 (분할 매수)**
```
2단계: RSI 26~28, -3% 하락 → 10,000원
3단계: RSI 24~26, -5% 하락 → 10,000원
4단계: RSI 22~24, -7% 하락 → 10,000원
```
- 가격이 **떨어질수록** 추가 매수
- 각 단계별 **10분 간격** 확인

#### **✓ 5단계 매수 (최종 승부)**
```
조건: RSI <22, -10% 하락
금액: 100,000원 (대량!)
```
- 정말 저평가된 상황에서만 발동
- **가장 위험하지만 수익 가능성 큰 구간**

### **🎯 매도 로직 확인:**

#### **✓ 1차 익절**
```
조건: +2.5% 이상
매도: 보유량의 50%
```
- 수익이 나면 **절반 먼저 매도**
- 안전하게 수익 확보

#### **✓ 2차 익절**
```
조건: +2.0% 이상
매도: 남은 보유량의 60% (전체의 30%)
```

#### **✓ 3차 익절**
```
조건: +1.5% 이상
매도: 남은 전량 (전체의 20%)
```

#### **✓ 손절**
```
조건: -15% 이하
매도: 전량 (100%)
단, 첫 1시간은 손절 안 함 (안전 모드)
```

### **🎯 수익 재투자 확인:**

```
매도 후 순서대로:
1. SOL 10,000원
2. XRP 10,000원
3. BTC 10,000원
4. HBAR 10,000원
```
- 로그에서 **"수익 분산 투자"** 찾기
- 순서대로 진행되는지 확인

### **🎯 안전 장치 확인:**

#### **✓ 시드 보호**
```
현재 KRW < 초기 시드
→ 추가 매수 중단
```
- 손실이 커지는 걸 방지
- 로그에서 **"시드 보호"** 확인

#### **✓ 첫 1시간 손절 보호**
```
봇 시작 후 1시간 동안:
-15% 이하여도 손절 안 함
```
- 로그에서 **"안전 모드 활성화"** 확인
- 남은 시간 표시

#### **✓ 최소 매수 금액**
```
5,000원 미만 매수 취소
```
- 수수료 낭비 방지

## ✅ **5. 시뮬레이션 기간별 체크리스트**

### **🕐 첫 1시간:**
- [ ] 봇이 정상 실행되는지
- [ ] 웹 대시보드 접속 되는지
- [ ] 현재 보유 코인 정보가 보이는지
- [ ] 로그가 계속 출력되는지
- [ ] **안전 모드 활성화** 로그 확인

### **🕑 2~6시간:**
- [ ] 매수 신호가 발생했는지
- [ ] RSI 조건이 맞게 작동하는지
- [ ] 매수 단계가 순서대로 진행되는지
- [ ] 로그에 **"[시뮬레이션 모드]"** 표시 확인

### **🕒 6~24시간:**
- [ ] 매도 신호가 발생했는지
- [ ] 수익률 계산이 정확한지
- [ ] 수익 재투자가 작동하는지
- [ ] 손절 조건 (테스트 어려움)
- [ ] 시드 보호 작동 여부

### **📅 24시간 이후:**
- [ ] 총 수익/손실 확인
- [ ] 거래 횟수 확인
- [ ] bot.log 파일 복기
- [ ] 예상치 못한 동작 없는지
- [ ] 실전 전환 준비 완료

## 🎯 **시뮬레이션에서 꼭 확인해야 할 것 TOP 5**

### **1️⃣ 매수가 너무 자주 일어나지 않는가?**
```
✅ 정상: 하루에 0~5회 정도
⚠️ 주의: 하루에 10회 이상
❌ 문제: 계속 매수만 함
```

### **2️⃣ 손실이 -15%를 넘는 코인이 있는가?**
```
✅ 1시간 후: 손절 작동 확인
⚠️ 주의: -20% 이상
❌ 문제: 손절이 안 됨
```

### **3️⃣ 수익 재투자가 제대로 작동하는가?**
```
✅ 매도 후: SOL → XRP → BTC → HBAR 순서
⚠️ 주의: 순서가 섞임
❌ 문제: 재투자가 안 됨
```

### **4️⃣ 시드 보호가 작동하는가?**
```
✅ KRW < 초기 시드: 매수 중단 로그
⚠️ 주의: 경고만 뜨고 계속 매수
❌ 문제: 보호 안 됨
```

### **5️⃣ 로그가 이해되는가?**
```
✅ 왜 샀는지/팔았는지 이해됨
⚠️ 주의: 일부만 이해됨
❌ 문제: 전혀 이해 안 됨 → 실전 금지!
```
