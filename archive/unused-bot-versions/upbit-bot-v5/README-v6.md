# 🚀 업비트 스마트 봇 v6.0 - 라이선스 시스템

## ✨ **새로운 기능**

### **2가지 모드 지원**
```
🟢 연습 모드 (무료, 무제한)
- 실시간 시뮬레이션
- 수익 확인 가능
- 실제 거래 없음
```

## 🎯 **사용 흐름**

### **Phase 1: 연습 모드로 테스트** (필수!)
```
1. 봇 시작
2. API 키 입력 (⚙️ 버튼)
3. 연습 모드 선택 (기본값)
4. Bot Start 클릭
5. 24시간 이상 수익 확인
```

### **Phase 2: 확신이 들면 라이선스 구매**
```
1. "라이선스 활성화" 버튼 클릭
2. TRC-20 주소로 10 USDT 전송
   → TLb5D3uDQjPQt6CzATM21t21etxGsSvtbt
3. TXID 복사
4. 대시보드에서 TXID 입력
5. "TXID 검증 및 활성화" 클릭
```

### **Phase 3: 실전 모드 전환**
```
1. 라이선스 활성화 확인
2. "🔴 실전 모드" 버튼 클릭
3. 경고 메시지 확인
4. 확인 후 전환
5. Bot Start 클릭
6. 실제 거래 시작!
```

## 💳 **라이선스 시스템**

### **가격**
```
10 USDT (TRC-20) = 10일 실전 모드
```

### **결제 방법**
```
1. 네트워크: TRC-20 (Tron)
2. 주소: TLb5D3uDQjPQt6CzATM21t21etxGsSvtbt
3. 금액: 10 USDT 이상
4. 확인: TXID 자동 검증
```

### **TXID 검증 절차**
```
✅ 트랜잭션 존재 여부
✅ 성공적인 전송 확인
✅ USDT (TRC-20) 확인
✅ 수신 주소 일치
✅ 금액 10 USDT 이상
```

### **만료 알림**
```
• 3일 전: ⚠️ 만료 임박 알림
• 1일 전: ⚠️ 재구매 권장
• 만료 시: 🔴 자동으로 연습 모드 전환
```

## 🔧 **문제 해결**

### Q1: 라이선스 활성화가 안 돼요
**A:** 
1. TXID가 정확한지 확인
2. TRC-20 네트워크로 전송했는지 확인
3. 10 USDT 이상 전송했는지 확인
4. 수신 주소 일치 확인
5. 트랜잭션 완료 대기 (약 1분)

### Q2: 실전 모드 버튼이 비활성화되어 있어요
**A:** 
라이선스가 필요합니다.
1. "라이선스 활성화" 버튼 클릭
2. 10 USDT 전송
3. TXID 입력 및 검증

### Q3: 연습 모드와 실전 모드의 차이가 뭐예요?
**A:** 
- **연습 모드**: 실제 주문 없음, 시뮬레이션만
- **실전 모드**: 실제 주문 실행, 수익/손실 발생

### Q4: 라이선스가 만료되면 어떻게 되나요?
**A:** 
- 자동으로 **연습 모드**로 전환
- 데이터는 유지됨
- 재구매 후 다시 실전 모드 사용 가능

### Q5: TXID는 어디서 확인하나요?
**A:** 
- 업비트 출금 내역
- Trust Wallet 거래 내역
- TronScan.org에서 확인
- 예: https://tronscan.org/#/transaction/[TXID]
