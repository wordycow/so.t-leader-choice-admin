# 🚀 실전 모드 가이드

## ⚠️ **매우 중요! 반드시 읽으세요!**

실전 모드는 **실제 돈으로 거래**가 이루어집니다!
손실이 발생할 수 있으므로 신중하게 사용하세요.

## 📋 **실전 전환 전 필수 체크리스트**

### ✅ **1. 충분한 시뮬레이션 테스트**
- [ ] 시뮬레이션 모드로 최소 24시간 이상 테스트
- [ ] 로그를 확인하여 매매 로직 완전 이해
- [ ] 어떤 상황에서 매수/매도가 되는지 파악

### ✅ **2. 안전 설정 확인**
- [ ] **API Key 출금 권한 체크 해제** (필수!)
- [ ] 초기 투자금 10만원 이하로 설정
- [ ] 감당 가능한 손실 금액만 투자

### ✅ **3. 매매 로직 이해**
```
📊 매수 전략:
- 1단계: RSI 28~30 → 6,000원 매수
- 2단계: RSI 26~28, -3% 하락 → 10,000원 매수
- 3단계: RSI 24~26, -5% 하락 → 10,000원 매수
- 4단계: RSI 22~24, -7% 하락 → 10,000원 매수
- 5단계: RSI <22, -10% 하락 → 100,000원 매수

💰 매도 전략:
- +2.5% 수익: 보유량의 50% 매도
- +2.0% 수익: 보유량의 30% 매도
- +1.5% 수익: 보유량의 20% 매도

🔴 손절:
- -15% 이하: 전량 매도
- 단, 첫 1시간은 손절 보호 모드 (안전장치)
```

### ✅ **4. API Key 설정**
```
업비트 → 마이페이지 → Open API 관리

✅ 체크:
- 자산 조회
- 주문 조회
- 주문 하기

❌ 체크 해제 (필수!):
- 출금 (Digital Assets Withdrawal)
- 원화 출금 (KRW Withdrawal)
```

## 🔧 **실전 모드 실행 방법**

### **방법 1: 실전 전용 파일 사용** ⭐ (권장)

```
📂 upbit-bot-v5 폴더에서
👉 "실전시작.cmd" 더블클릭
```

**특징:**
- 실전 모드 전용 실행 파일
- 경고 메시지와 확인 절차 포함
- "yes" 입력해야만 시작

### **방법 2: 수동 전환**

1. 봇 중지
2. `upbit-smart-bot-v5.py` 파일 열기
3. 다음 3곳의 주석 제거:

#### **📍 위치 1: 수익 재투자 주문 (약 271번 라인)**
```python
# 변경 전:
# order = upbit.buy_market_order(next_target, PROFIT_INVEST_AMOUNT)

# 변경 후:
order = upbit.buy_market_order(next_target, PROFIT_INVEST_AMOUNT)
```

#### **📍 위치 2: 매수 주문 (약 527번 라인)**
```python
# 변경 전:
# order = upbit.buy_market_order(ticker, buy_amount)

# 변경 후:
order = upbit.buy_market_order(ticker, buy_amount)
```

#### **📍 위치 3: 매도 주문 (약 563번 라인)**
```python
# 변경 전:
# order = upbit.sell_market_order(ticker, sell_amount)

# 변경 후:
order = upbit.sell_market_order(ticker, sell_amount)
```

4. 저장
5. `START.bat` 또는 `봇시작.cmd` 실행

## 🛡️ **안전 기능**

### **1. 첫 1시간 손절 보호**
```
봇 시작 후 1시간 동안:
- 현재 손실이 -15% 이하여도 손절 안 됨
- 급격한 하락에서 회복 시간 제공
- 1시간 후 자동으로 정상 손절 활성화
```

### **2. 초기 시드 보호**
```
현재 KRW 잔고가 초기 시드 이하로 내려가면:
- 추가 매수 중단
- 경고 메시지 출력
- 손실 확대 방지
```

### **3. 최소 매수 금액**
```
매수 금액이 5,000원 미만이면:
- 자동으로 매수 취소
- 수수료 낭비 방지
```

## 📊 **실전 모드 vs 시뮬레이션 모드 차이**

| 항목 | 시뮬레이션 모드 | 실전 모드 |
|------|----------------|----------|

| 로그 표시 | [시뮬레이션 모드] | [실전 모드] |
| API 호출 | 조회만 | 주문도 실행 |
| 추천 용도 | 테스트, 학습 | 실제 거래 |

## 🎯 **실전 모드 시작 순서**

### **1단계: 준비**
```bash
✅ 시뮬레이션 24시간 이상 테스트 완료
✅ 로그 분석 완료
✅ 매매 로직 이해 완료
✅ API Key 출금 권한 체크 해제
```

### **2단계: 실행**
```bash
1. "실전시작.cmd" 더블클릭
2. 경고 메시지 확인
3. "yes" 입력
4. 웹 브라우저 자동 실행
```

### **3단계: 설정**
```bash
1. 웹 대시보드 접속 (http://localhost:5000)
2. ⚙️ 설정 버튼 클릭
3. API Key 입력 (출금 권한 없는 키!)
4. 저장
```

### **4단계: 시작**
```bash
1. ▶ Bot Start 클릭
2. 로그에서 "[실전 모드]" 확인
3. 대시보드에서 실시간 모니터링
```

### **5단계: 모니터링**
```bash
✅ 첫 1시간: 손절 보호 모드 작동 확인
✅ 매수/매도: 실제 거래 체결 확인
✅ 잔고: KRW 및 코인 보유량 변화 확인
✅ 수익: 실시간 수익률 확인
```

## ❓ **자주 묻는 질문 (FAQ)**

### Q1: 실전 모드로 바꾸면 바로 거래가 되나요?
**A:** 네! 조건이 맞으면 즉시 실제 주문이 실행됩니다.

### Q2: 지금 손실 코인이 있는데 실전 모드로 시작하면?
**A:** 
- 첫 1시간은 손절 보호 모드
- -15% 이하여도 매도 안 됨
- 1시간 후 정상 손절 활성화

### Q3: 실수로 실전 모드를 켰어요!
**A:** 
1. 즉시 웹에서 "⏸ Bot Stop" 클릭
2. 또는 CMD 창에서 Ctrl+C
3. 이미 체결된 주문은 업비트에서 수동 처리

### Q4: 수익이 나면 자동으로 재투자되나요?
**A:** 
- 네! 매도 후 자동으로:
  - SOL (10,000원)
  - XRP (10,000원)
  - BTC (10,000원)
  - HBAR (10,000원) 순차 매수

### Q5: 시뮬레이션으로 돌아가려면?
**A:** 
1. 봇 중지
2. `봇시작.cmd` 또는 `START.bat` 실행
   (원래 upbit-smart-bot-v5.py 파일 사용)
