# 업비트 스마트 봇 v5.0 - 완벽 설치 가이드

## 🚀 **초간단 실행 방법** (3분 완성!)

### **1단계: 파일 다운로드 및 압축 해제**
1. 다운로드: `upbit-bot-v5-SAFE-NEW.zip` (17KB)
2. 압축 해제 → `upbit-bot-v5` 폴더 생성됨

---

### **2단계: 설치 실행** ⭐
**3가지 방법 중 하나 선택:**

#### ✅ **방법 A: .cmd 파일 실행** (가장 쉬움!)
```
📁 upbit-bot-v5 폴더 안에서
👉 "설치시작.cmd" 더블클릭
```
- 자동으로 관리자 권한 요청
- Python + 모든 라이브러리 자동 설치 (5분 소요)

#### ✅ **방법 B: 우클릭 실행**
```
INSTALL.bat 우클릭 → "관리자 권한으로 실행" 선택
```

#### ✅ **방법 C: CMD 창에서 실행**
```
1. 폴더 주소창에 "cmd" 입력 → 엔터
2. 나타난 창에서:
   INSTALL.bat
   (엔터)
```

---

### **3단계: 봇 시작**
설치 완료 후:

#### ✅ **방법 A: .cmd 파일 실행** (추천!)
```
👉 "봇시작.cmd" 더블클릭
```
- 웹브라우저가 자동으로 열립니다 (http://localhost:5000)

#### ✅ **방법 B: 기존 방식**
```
START.bat 더블클릭
```

---

### **4단계: API 키 입력**
1. 웹 대시보드에서 **⚙️ 설정** 버튼 클릭
2. **Access Key** / **Secret Key** 입력
   - Upbit → 마이페이지 → Open API 관리 → API Key 발급
   - **주의:** "출금 권한" 체크 해제!!
3. **저장** 클릭

---

### **5단계: 봇 시작!**
- **▶ Bot Start** 버튼 클릭
- 대시보드에서 실시간 모니터링

## ❓ **자주 묻는 질문 (FAQ)**

### Q1: Python이 없다고 나와요!
**A:** https://www.python.org/downloads/ 에서 다운로드
- 설치 시 **"Add Python to PATH"** 반드시 체크!

### Q2: 파일이 텍스트로 열려요!
**A:** 
- **"설치시작.cmd"** 파일을 사용하세요 (자동 실행됨)
- 또는 INSTALL.bat 우클릭 → "관리자 권한으로 실행"

### Q3: Flask 오류가 나요!
**A:** 설치가 제대로 안 된 것입니다.
```bash
python -m pip install --user flask flask-cors pyupbit pandas numpy requests
```

### Q4: 지금 연결하면 손절이 바로 되나요?
**A:** 아니요! **안전 모드 (1시간)** 작동
- 봇 시작 후 1시간 동안은 -15% 이하여도 손절 안 됨
- 1시간 후 정상 손절 활성화

### Q5: 실제 거래가 되나요?
**A:** 기본값은 **시뮬레이션 모드**
- 로그에 "[시뮬레이션 모드]" 표시
- 실제 주문은 실행되지 않음
- 충분한 테스트 후 라이브 모드 전환 권장
