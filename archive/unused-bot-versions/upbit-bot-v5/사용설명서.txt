🤖 업비트 스마트 봇 v5.0 - 사용 설명서
================================================================

✅ 빠른 시작 (2단계)
================================================================

1단계: INSTALL.bat 더블 클릭
   → 모든 라이브러리 자동 설치 (5분)
   → Flask, flask-cors, pyupbit, pandas, numpy, requests

2단계: START.bat 더블 클릭
   → 웹 브라우저 자동 열림 (http://localhost:5000)
   → API 키 입력
   → [▶ 봇 시작] 클릭


🔧 수동 설치 (INSTALL.bat 실행 안 될 때)
================================================================

명령 프롬프트(cmd)를 관리자 권한으로 실행 후:

cd 이_폴더_경로
python -m pip install --user --upgrade pip
python -m pip install --user -r requirements.txt
python upbit-smart-bot-v5.py


🛑 봇 중지 방법
================================================================

웹 대시보드 (추천): [⏸ 봇 중지] 버튼 클릭
터미널 창: cmd 창 닫기
키보드: Ctrl+C


⚠️ Python 필수!
================================================================

Python 3.8 이상 필요
다운로드: https://www.python.org/downloads/

설치 시 반드시 체크:
☑ Add Python to PATH


✨ 주요 기능
================================================================

💰 5단계 분할 매수
   - 1단계: 6,000원 (RSI 28-30)
   - 2-4단계: 각 10,000원
   - 5단계: 100,000원

📈 3단계 분할 익절
   - 1차: 50% @ +2.5%
   - 2차: 30% @ +2.0%
   - 3차: 20% @ +1.5%

💎 수익 자동 재투자
   - SOL, XRP, BTC, HBAR (각 10,000원)

🛡️ 시드 보호
   - 초기 자본 절대 보존

🌐 웹 대시보드
   - 실시간 모니터링 (3초 업데이트)


❓ 자주 묻는 질문
================================================================

Q: INSTALL.bat 실행 시 오류가 나요
A: 명령 프롬프트를 관리자 권한으로 실행 후:
   cd 폴더경로
   python -m pip install --user flask flask-cors pyupbit pandas numpy requests

Q: "Python이 없습니다" 오류
A: Python 설치 필요
   https://www.python.org/downloads/
   설치 시 "Add Python to PATH" 체크!

Q: 웹 페이지가 안 열려요
A: 브라우저에서 직접 입력
   http://localhost:5000

Q: 봇이 거래를 안 해요
A: 기본은 시뮬레이션 모드입니다.
   실전 모드는 upbit-smart-bot-v5.py 파일에서
   주석(#) 제거 필요 (README 참고)
