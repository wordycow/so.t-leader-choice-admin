현금흐름 계산기 (신규/갱신 분리 + 직급수당 + 여행정산)

입력값만 바꾸면 “들어온 USDT / 나갈 USDT / 현재 사용가능 자금(추정)”이 자동 계산됩니다.

기본 입력

참고 신규 1회차만 추천수당이 나간다면, “newSubs”에만 추천수당이 적용됩니다.

여행 정산(현금) 추정

① 예상 지급(준비금): u로 계산 (운영 안전용)
② 실제 지급(현금유출): 여행 다녀온 인원×1인 지급액(선택)

직급수당 (2회차+ 기준: 60일 / 신규는 선택적으로 53일 적용)

입력 방법 아래 표의 “수령자 수”는 직급수당을 실제로 받는 사람 수를 넣으면 됩니다. “하향 적용 인원”은 3회차(120일+) 시작 시점에 성장 없어서 한 단계 낮게 받는 사람 수(갱신쪽에만 보통 적용)를 넣으세요.
직급 일 지급액 신규 수령자(1회차) 갱신 수령자(2회차+) 하향 적용(갱신 중) 이번 기간 직급수당 합계
※ “하향 적용”은 해당 직급에서 빼고(원직급 지급 제거), 한 단계 아래 직급 지급으로 자동 이동 계산됩니다.

결과

총 유입(구독) = 0
출금수수료 수익(선택) = 0
총 유입 합계 = 0
추천수당(신규 1회차만) = 0
직급수당(이번 기간) = 0
여행 실제지급(선택) = 0
운영비/기타 = 0
운영 안전용 여행 예상지급(준비금) = 0
= (이번 기간 적립포인트 가치) × u × (연차 상한 선택값)
총 유출(실제) = 0
현재 사용가능 자금(추정) = 0
= 총 유입 − (추천수당+직급수당+여행실제지급+운영비)
주의: 여행은 “실제 지급”이 없더라도 포인트 부채가 누적됩니다. 그래서 운영은 “예상지급(준비금)”을 별도로 보는 게 안전합니다.
