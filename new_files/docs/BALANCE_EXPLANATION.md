# ⚠️ 시드 잔고 변동 설명 (Why Balance Changes Immediately)

## 🔍 문제 상황

**사용자 보고**: 
- 300만원 시드로 봇 시작
- 즉시 270만원으로 감소 (30만원 손실)
- 거래 내역은 보이지 않음
- "믿을 수 없는 데이터"라고 느낌

## ✅ 원인 분석 및 해결

### 1️⃣ **즉시 거래 실행 (정상 동작)**

**봇의 동작 방식**:
```
봇 시작 → 0~5초 내 → 급등/급락 패턴 감지 → 즉시 매수
```

**실제 테스트 결과**:
```
초기 시드: 1,000,000원
2초 후 잔고: 850,000원  (15% 감소)
거래 내역: 1건 - BUY KRW-DOT 75.0751개 @ 1,998원
```

**이유**:
- 봇이 시작되면 **즉시 인기 종목을 스캔**
- 급등/급락/박스권 등 **패턴을 감지**하면 바로 매수
- 150,000원을 DOT 코인 구매에 사용 (시드의 ~15%)
- 따라서 **현금 잔고가 줄어드는 것은 정상**

### 2️⃣ **거래 내역 미표시 (버그 - 수정 완료)**

**문제**:
- 백엔드는 `recent_trades: []` (빈 배열) 반환
- 프론트엔드는 거래 내역을 표시하지 않음
- 사용자는 "돈만 사라지고 거래 내역이 없다"고 느낌

**해결**:
```python
# bot_state에 거래 내역 추적 추가
'recent_trades': deque(maxlen=50),

# 매수 실행 시
bot_state['recent_trades'].append({
    'ticker': ticker,
    'type': 'BUY',
    'amount': buy_amount,
    'price': current_price,
    'timestamp': datetime.now().isoformat()
})

# 매도 실행 시
bot_state['recent_trades'].append({
    'ticker': ticker,
    'type': 'SELL',
    'amount': holding['amount'],
    'price': current_price,
    'profit_rate': profit_rate,
    'timestamp': datetime.now().isoformat()
})
```

**결과**:
- `/api/status`가 최근 10건 거래 반환
- 프론트엔드에 실시간 표시 (3초마다 업데이트)
- 사용자가 **언제, 무엇을, 얼마에 샀는지** 투명하게 확인 가능

## 📊 올바른 잔고 계산 공식

### **총 자산 = 현금 잔고 + 보유 코인 가치**

**예시**:
```
초기 시드: 1,000,000원

[매수 직후]
현금 잔고:   850,000원
보유 코인:   KRW-DOT 75.0751개 @ 1,998원 = 150,000원
─────────────────────────
총 자산:     1,000,000원  ← 손실 없음!
총 손익:     0원 (0.00%)
```

**시장가 변동 후**:
```
[DOT 가격 상승: 1,998원 → 2,100원]
현금 잔고:   850,000원
보유 코인:   KRW-DOT 75.0751개 @ 2,100원 = 157,658원
─────────────────────────
총 자산:     1,007,658원
총 손익:     +7,658원 (+0.77%)
```

## 🎯 정상 동작 흐름

### **Phase 1: 매수 실행** (0~10초)
```
1. 봇 시작 (시드 입력)
2. 인기 종목 스캔 (상위 50개)
3. 패턴 감지 (급등/급락/박스권)
4. 조건 충족 시 즉시 매수
5. 현금 잔고 감소 (코인 구매)
6. 거래 내역에 "매수" 기록
```

### **Phase 2: 보유 및 모니터링** (10초~수분)
```
1. 코인 가격 실시간 추적
2. 수익률 계산: (현재가 - 매수가) / 매수가 × 100
3. 목표 수익률 도달 또는 손절 조건 충족 시 매도
```

### **Phase 3: 매도 실행** (조건 충족 시)
```
1. 수익률 +1.5% / +2.5% / +4.0% 또는 손절 -2%
2. 매도 체결
3. 현금 잔고 증가
4. 거래 내역에 "매도 +X%" 기록
5. 전략 성과 업데이트 (승률, 수익률)
```

## ⚠️ 사용자 주의사항

### ✅ **정상 현상**
- 봇 시작 후 즉시 잔고 감소 (코인 매수)
- 현금 잔고가 줄어도 **총 자산은 동일**
- 거래 내역에 "BUY" 표시

### ❌ **비정상 현상** (이제 수정됨)
- 잔고 감소했는데 거래 내역 없음 → **수정 완료**
- 총 자산이 시드보다 적음 (매수 직후) → **버그 수정 필요**
- 거래 없이 손실 발생 → **버그 수정 필요**

## 🧪 테스트 권장사항

### **Phase 1: 초기 거래 확인** (1분)
1. 연습 모드 선택
2. 시드 100만원 입력
3. "🚀 봇 시작" 클릭

   - "BUY" 표시 확인
   - 코인명, 수량, 가격 확인
   - 잔고 변화 확인

1. 3초마다 자동 업데이트 확인
2. 수익률 변동 관찰
3. 전략 카드 업데이트 확인

### **Phase 3: 매도 확인** (10~30분)
1. 목표 수익률 도달 시 자동 매도
2. "SELL +X%" 거래 내역 확인
3. 총 손익 및 수익률 확인
