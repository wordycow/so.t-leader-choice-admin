## 📦 **설치 방법**

### **⚠️ 설치 전 필수 확인 사항**
```
✅ Windows 10 이상
✅ 인터넷 연결 필수
✅ Python 3.8 이상 (없으면 자동 안내)
```

### **1단계: 설치**
```
1. "설치시작.cmd" 더블클릭
2. Python이 없다면:
   → 자동으로 Python 다운로드 페이지 열림
   → 다운로드 후 설치 (⚠️ "Add Python to PATH" 체크!)
   → 설치 완료 후 컴퓨터 재시작
   → 다시 "설치시작.cmd" 실행
3. Python이 있다면:
   → 자동으로 라이브러리 설치 (2-5분 소요)
   → "설치가 완료되었습니다!" 메시지 확인
```

### **2단계: 실행**
```
1. "START.cmd" 더블클릭
2. 자동 확인:
   ✓ Python 설치 확인
   ✓ 라이브러리 확인
   ✓ 포트 5000 사용 가능 확인
3. 웹 브라우저 자동 실행 (http://localhost:5000)
4. 콘솔 창은 닫지 마세요! (봇 실행 중)
```

### **❌ 문제가 발생하면?**
```
→ "문제해결가이드.md" 파일 참고
→ 또는 GitHub Issues에 문의
```

[11:00:23] ✅ 매도 이유 기록 완료 - 목표 수익률 2.5% 달성 성공 (실제: 3.1%)

# 봇 종료 시 세션 결과:
📈 세션 결과:

  최종 잔고: 1,050,000원

## 🔧 **문제 해결**

### Q1: 라이선스 활성화가 안 돼요
**A:** 
1. TXID가 정확한지 확인
2. TRC-20 네트워크로 전송했는지 확인
3. 10 USDT 이상 전송했는지 확인
4. 수신 주소 일치 확인
5. 트랜잭션 완료 대기 (약 1분)

### Q2: 실전 모드 버튼이 비활성화되어 있어요
**A:** 
라이선스가 필요합니다.
1. "라이선스 활성화" 버튼 클릭
2. 10 USDT 전송
3. TXID 입력 및 검증

### Q3: 연습 모드와 실전 모드의 차이가 뭐예요?
**A:** 
- **연습 모드**: 실제 주문 없음, 시뮬레이션만
- **실전 모드**: 실제 주문 실행, 수익/손실 발생

### Q4: 라이선스가 만료되면 어떻게 되나요?
**A:** 
- 자동으로 **연습 모드**로 전환
- 데이터는 유지됨
- 재구매 후 다시 실전 모드 사용 가능

### Q5: TXID는 어디서 확인하나요?
**A:** 
- 업비트 출금 내역
- Trust Wallet 거래 내역
- TronScan.org에서 확인
- 예: https://tronscan.org/#/transaction/[TXID]
